# 배포 검증

대상: ImageSearch 1.1.0 (원본 화질, 페이징, 아이콘·애니메이션, 라이트/다크 테마).

## 통과한 것

- 자동 테스트 **40개** 통과 (`pytest -q`, Python 3.11 / Qt 6.11.2 offscreen).
  - 저장소 영속성, upsert가 좋아요·파일 경로를 보존하는지
  - 미리보기가 **썸네일이 아니라 원본**에서 만들어지는지, 원본이 거부될 때만 썸네일로 대체되는지
  - 1600px 초과 이미지만 축소되고 작은 원본은 바이트 그대로 보관되는지, 투명도가 유지되는지
  - 다운로드한 파일에서 미리보기를 파생시키는지 (네트워크 재요청 없음)
  - 추가 페이지가 이미 본 URL을 중복으로 넣지 않는지, 빈 페이지가 반복되면 종료하는지
  - 취소된 검색과 다른 검색어의 늦은 응답을 버리는지
  - 두 테마의 팔레트 토큰이 일치하고, UI가 쓰는 아이콘이 모두 번들에 있는지
  - 카드가 화면 픽셀 비율에 맞춰 그려지는지, 작은 원본을 1.4배 넘게 늘리지 않는지
  - 120장 목록에서 화면에 보이는 카드만 미리보기를 요청하는지, 스크롤하면 나머지가 채워지는지
  - 테마 전환이 카드 목록을 잃지 않고 다음 실행까지 유지되는지
- 통제된 로컬 HTML로 추출 로직 검증 (`verify_search.py`): 원본 URL, 한글 제목, 해상도, 출처.
- 자동 수집 흐름 검증 (`verify_auto_search.py`): 가져오기 버튼 없음, 결과 자동 전달, 시간 초과 시 팝업 없음, 늦은 페이지 로드 복구, 취소 상태 유지.
- 문서 스크린샷은 **빈 임시 데이터 폴더**로 실행한 실제 앱 화면입니다 (`scripts/capture_ui.py`). 개인 라이브러리·검색 기록·계정이 포함되지 않으며, 표시된 이미지는 합성 픽스처입니다.

## 검증하지 못한 것

- **실제 Google 실검색의 전체 성공.** 개발 네트워크에서 Google이 CAPTCHA를 요구해 끝까지 확인하지 못했습니다. 스크롤 페이징 로직은 기록된 응답으로만 검증했으며, 실제 Google 페이지에서 수집되는 이미지 수는 네트워크·지역·페이지 구조에 따라 달라집니다.
- **SerpApi 실계정 호출.** 개인 API 키가 없어 실행하지 않았습니다. `ijn` 페이지 파라미터를 사용하는 경로도 마찬가지입니다.
- **macOS 앱 번들 재빌드.** 이번 수정본은 macOS 머신에서 다시 빌드하지 못했습니다. 배포 앱은 `release-macos.yml` 워크플로(GitHub Actions macOS 러너)로 태그에서 빌드하거나, 로컬에서 `python scripts/build.py` 로 만들어야 합니다. 저장소의 소스는 최신입니다.
- **Windows / Linux 실행**과 **Apple Silicon 네이티브 빌드**는 이번에도 확인하지 않았습니다.
- 애니메이션(좋아요 팝, 저장 스피너, 페이드인)은 오프스크린 캡처로 정지 화면만 확인했습니다. 움직임 자체는 자동 검증 대상이 아닙니다.

- 소스와 문서에서 개발자 계정, 개인 이메일, 로컬 절대 경로, API 키, 토큰을 검색해 제외했습니다.
