# 사용 가이드

## 1. 검색하기

화면 아래 입력창에 찾고 싶은 것을 적고 <kbd>Enter</kbd> 를 누릅니다. 캐릭터 이름, 작품 제목, 분위기 모두 됩니다.

- <kbd>Shift</kbd>+<kbd>Enter</kbd> — 줄바꿈
- <kbd>Ctrl</kbd>+<kbd>L</kbd> — 검색창으로 이동
- **2D · 애니메이션 키워드 추가** — 켜 두면 검색어에 애니메이션·일러스트 관련 단어를 덧붙여 2D 이미지가 더 많이 나옵니다. 실사 사진을 찾을 때는 끄세요.
- 검색 중 나타나는 **✕** 버튼으로 언제든 중지할 수 있습니다.

결과가 준비되면 위쪽 격자에 자동으로 나타납니다. 따로 눌러야 하는 가져오기 버튼은 없습니다.

### 더 많은 결과 보기

목록 끝까지 스크롤하면 Google의 다음 이미지들을 이어서 불러옵니다. 목록 아래 **더 불러오기** 버튼을 직접 눌러도 됩니다. 한 검색에서 최대 500장까지 모읍니다. 더 이상 새 이미지가 없으면 “Google이 제공한 결과를 모두 불러왔습니다”라고 알려 주고 버튼이 사라집니다.

### Google 확인이 필요할 때

Google이 사람 확인(CAPTCHA)이나 쿠키 동의를 요구하면 검색이 멈추고 안내 문구가 나옵니다. 오른쪽 위 **Google 확인** 을 눌러 열리는 창에서 직접 확인을 마치면, 그 뒤로는 결과를 자동으로 가져옵니다. 앱이 확인 절차를 대신 통과하지는 않습니다.

확인 창에서 마음에 드는 이미지를 직접 오른쪽 클릭해 **이 이미지를 ImageSearch로 가져오기** 를 선택할 수도 있습니다.

### SerpApi (선택 사항)

확인 화면이 반복돼 불편하면 사이드바의 **검색 설정** 에서 SerpApi의 Google Images API로 바꿀 수 있습니다. 본인의 API 키가 필요하고 사용량·비용은 본인 계정에 부과됩니다. 키는 이번 실행 동안 메모리에만 보관하며 파일이나 DB에 기록하지 않습니다. 환경변수 `SERPAPI_API_KEY` 로도 지정할 수 있습니다.

## 2. 화질에 대해

미리보기는 Google 썸네일이 아니라 **검색 결과의 원본 이미지**에서 만듭니다.

- 원본이 1600px 이하이고 파일이 작으면 손대지 않고 그대로 보관합니다.
- 더 큰 이미지는 긴 변 1600px, 품질 92의 JPEG(투명도가 있으면 PNG)로 줄여 캐시합니다.
- 카드와 확대 보기는 화면의 픽셀 밀도(Retina 등)에 맞춰 그립니다.
- 원본 서버가 접근을 거부하면 그때만 Google 썸네일로 대체하고, 카드가 흐릿하게 보일 수 있습니다.
- 카드에 표시되는 `1920×1080` 은 Google이 알려 준 **원본 해상도**입니다. 실제 그 크기의 파일이 필요하면 **저장** 을 눌러 원본을 내려받으세요.

화면에 보이는 카드만 이미지를 요청합니다. 스크롤을 내리면 그때 다음 카드들이 채워집니다.

## 3. 좋아요

카드의 하트를 누르면 좋아요 목록에 들어갑니다. 이때 미리보기 파일이 기기에 저장되므로, 다음에 앱을 켰을 때 **검색하지 않고 인터넷 없이도** 볼 수 있습니다.

미리보기 저장에 실패하면 좋아요 자체는 남지만 이미지 자리가 비어 있을 수 있습니다. 연결된 상태에서 목록을 다시 열면 재시도합니다.

## 4. 다운로드

**저장** 을 누르면 원본 파일을 백그라운드로 내려받습니다. 저장이 끝나면 버튼이 **저장됨** 으로 바뀌고, 다시 누르면 파일이 열립니다. 내려받은 파일은 왼쪽 **다운로드** 목록에 모입니다.

- 한 파일당 35MB, 60초 제한이 있습니다.
- 이미지가 아닌 응답, 지원하지 않는 형식, 거부된 요청은 실패로 표시됩니다.
- 다운로드가 끝나면 그 파일로 미리보기를 다시 만들기 때문에 네트워크를 한 번 더 쓰지 않습니다.
- 다운로드 중에 앱을 닫으면 저장을 마무리한 뒤 종료합니다.

## 5. 카테고리

왼쪽 **카테고리** 옆 `＋` 로 새 카테고리를 만듭니다. 카드의 태그 버튼을 누르면 어느 카테고리에 넣을지 고를 수 있고, **한 이미지를 여러 카테고리에 함께** 넣을 수 있습니다.

카테고리 이름을 오른쪽 클릭하면 이름 변경과 삭제가 나옵니다. 카테고리를 지워도 좋아요와 내려받은 파일은 그대로 남습니다.

## 6. 테마

사이드바 아래쪽 **라이트 모드 / 다크 모드** 또는 <kbd>Ctrl</kbd>+<kbd>T</kbd> 로 전환합니다. 선택한 테마는 로컬 DB에 저장되어 다음 실행에도 유지됩니다.

## 7. 다시 찾기

- **최근 검색** — 사이드바에서 최근 8개 검색어를 다시 실행
- **현재 목록에서 찾기** — 지금 보이는 목록만 제목·출처로 걸러 냅니다 (새 검색이 아닙니다)
- **내 라이브러리** — 좋아요·다운로드·카테고리에 담긴 이미지 전체
- 이미지를 클릭하면 확대 보기와 **원본 출처** 링크가 열립니다

## 8. 저장 위치와 백업

| 운영체제 | 위치 |
|---|---|
| macOS | `~/Library/Application Support/ImageSearch/` |
| Windows | `%LOCALAPPDATA%\ImageSearch\` |
| Linux | `$XDG_DATA_HOME/imagesearch/` 또는 `~/.local/share/imagesearch/` |

사이드바의 **저장 폴더 열기** 로 바로 열 수 있습니다. 폴더 안에는 `library.sqlite3`(목록·좋아요·카테고리·설정), `previews/`, `downloads/`, Google 확인용 `browser/` 프로필이 있습니다. 앱을 완전히 종료한 뒤 폴더를 통째로 복사하면 백업됩니다.

환경변수 `IMAGESEARCH_DATA_DIR` 로 다른 폴더를 지정할 수 있습니다.

## 9. 문제 해결

| 증상 | 확인할 점 |
|---|---|
| 결과가 오지 않음 | **Google 확인** 을 눌러 확인 절차를 마치세요. 확인 후에는 자동으로 표시됩니다. |
| 계속 확인 화면만 나옴 | 잠시 후 다시 시도하거나, 검색 설정에서 SerpApi 키를 연결하세요. |
| 이미지가 흐릿함 | 원본 서버가 접근을 거부해 썸네일로 대체된 경우입니다. **저장** 으로 원본을 직접 받아 보세요. |
| 더 불러오기가 없음 | 그 검색에서 Google이 줄 수 있는 결과를 모두 가져온 상태입니다. |
| 다운로드 실패 | 원본 사이트가 외부 접근을 막았거나 35MB를 넘는 파일입니다. **원본 출처** 에서 직접 확인하세요. |
| “이미 실행 중입니다” | 열려 있는 ImageSearch 창을 확인하세요. 창이 없다면 저장 폴더의 `app.lock` 을 지우고 다시 실행합니다. |
| macOS가 앱 실행을 막음 | 공증되지 않은 앱입니다. 시스템 설정 → 개인정보 보호 및 보안에서 실행 허용을 확인하세요. |
