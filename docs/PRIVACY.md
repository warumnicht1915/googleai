# 개인정보와 공개 배포

## 앱이 저장하는 데이터

각 사용자의 OS 앱 데이터 폴더에 이미지 주소·제목·출처, 좋아요, 카테고리, 검색 기록, 미리보기, 다운로드 파일을 저장합니다. Google 확인용 Chromium 프로필은 같은 폴더 아래 `browser/`와 `browser-cache/`에 보관합니다.

검색어와 검색 요청은 Google 또는 사용자가 선택한 SerpApi로 전송됩니다. 이미지 다운로드는 해당 이미지 서버로 요청합니다. 이 앱 자체의 회원 계정, 분석 서버, 광고 SDK, 클라우드 동기화는 없습니다. 외부 사이트는 각각의 개인정보 처리 방침을 적용합니다.

SerpApi 키는 현재 실행 메모리에서만 사용하며 설정 파일/DB에 기록하지 않습니다. API 요청 주소에 키가 포함될 수 있으므로 네트워크 오류 메시지에 전체 요청 URL을 표시하지 않습니다.

테마 선택(라이트/다크)은 같은 로컬 DB의 `settings` 표에 저장되며 외부로 전송되지 않습니다. 아이콘은 저장소에 함께 담긴 정적 SVG 파일(Lucide, ISC)이라 실행 중 외부 CDN을 호출하지 않습니다.

## 이번 공개 파일에서 제외한 것

- 개발자의 라이브러리 DB, 좋아요, 검색 기록, 다운로드
- Google 브라우저 프로필, 쿠키, 캐시 및 로그인 세션
- `.env`, API 키, GitHub 인증 토큰, 개인 이메일 설정
- 개발용 가상환경, 로그, 기존 빌드 폴더, 로컬 절대 경로가 있는 진단 기록
- 스크린샷의 개인 계정/검색 내용: `scripts/capture_ui.py` 가 임시 디렉터리에 만든 합성 이미지로만 캡처

새 Git 커밋은 프로젝트 이름과 공개 저장소 소유자의 GitHub noreply 이메일을 사용합니다. 기존 원격 저장소의 커밋 이력은 변경하지 않습니다. 저장소 URL에 표시되는 공개 GitHub 사용자명은 배포 위치를 나타내기 위해 유지됩니다.

배포 바이너리는 별도의 임시 디렉터리에서 다시 빌드하고, 포함된 Python 아카이브까지 검사합니다. 검사 결과는 `VALIDATION.md`에 요약하며 개인 문자열을 검사 보고서에 기록하지 않습니다.
